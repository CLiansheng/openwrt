# NetPulse OpenWrt 使用文档

## 1. 项目位置

项目目录：

```text
C:\Users\admin\Desktop\计网实验\netpulse-openwrt
```

主要文件：

```text
src/netpulse_server.c        后端主程序
web/index.html               前端页面
web/style.css                前端样式
web/app.js                   前端逻辑
scripts/firewall.sh          防火墙脚本
scripts/run_openwrt.sh       OpenWrt 启动脚本
docs/实验报告草稿.md          报告草稿
docs/演示视频脚本.md          录屏讲稿
```

## 2. OpenWrt 虚拟机启动

桌面已有镜像：

```text
C:\Users\admin\Desktop\openwrt-24.10.0-x86-64-generic-ext4-combined-efi.vmdk
```

用 VMware 新建虚拟机时选择该 vmdk 作为磁盘。网络模式建议选择 NAT。

进入 OpenWrt 后检查网络：

```sh
ip addr
ping 223.5.5.5
```

如果没有网络，检查 `/etc/config/network` 中的 IP、网关和 DNS，然后重启网络：

```sh
/etc/init.d/network restart
```

记下 OpenWrt 的 IP，例如：

```text
192.168.100.2
```

## 3. 安装运行依赖

在 OpenWrt 控制台执行：

```sh
opkg update
opkg install libpcap nftables
```

如果需要用 Web 管理界面或共享目录传文件，可安装：

```sh
opkg install luci luci-app-samba4
```

## 4. 编译程序

推荐使用 OpenWrt SDK 或 Linux/WSL 交叉编译。项目已提供 `Makefile`。

OpenWrt SDK 编译命令参考：

```sh
export SDK=/path/to/openwrt-sdk-24.10.0-x86-64
export STAGING_DIR=$SDK/staging_dir
export TARGET_DIR=$STAGING_DIR/target-x86_64_musl
export TOOLCHAIN_DIR=$(ls -d $STAGING_DIR/toolchain-x86_64_*_musl)
export PATH=$TOOLCHAIN_DIR/bin:$PATH

make clean
make openwrt-dynamic CC=x86_64-openwrt-linux-musl-gcc
```

编译完成后得到：

```text
build/openwrt/netpulse_server
```

这个版本会在 OpenWrt 运行时动态加载 `libpcap.so.1`，所以交叉编译时不需要单独编译 libpcap 开发库。

也可以直接打包上传文件：

```sh
make package-openwrt CC=x86_64-openwrt-linux-musl-gcc
```

生成：

```text
build/netpulse-openwrt-upload.tar.gz
```

## 5. 上传到 OpenWrt

在 OpenWrt 上创建目录：

```sh
mkdir -p /usr/local/netpulse
```

将这些内容上传到 `/usr/local/netpulse`：

```text
build/openwrt/netpulse_server
web/
scripts/
```

最终结构应为：

```text
/usr/local/netpulse/netpulse_server
/usr/local/netpulse/web/index.html
/usr/local/netpulse/web/style.css
/usr/local/netpulse/web/app.js
/usr/local/netpulse/scripts/firewall.sh
/usr/local/netpulse/scripts/run_openwrt.sh
```

设置权限：

```sh
cd /usr/local/netpulse
chmod +x netpulse_server scripts/*.sh
```

## 6. 启动服务

先查看 OpenWrt 的网卡：

```sh
ip addr
```

常见接口是 `br-lan`，如果不同就替换为实际接口。

启动：

```sh
cd /usr/local/netpulse
./scripts/run_openwrt.sh br-lan 8080
```

看到以下输出表示启动成功：

```text
NetPulse server listening on http://0.0.0.0:8080
Capture interface: br-lan
```

## 7. 打开前端页面

在宿主机浏览器访问：

```text
http://OpenWrt_IP:8080
```

例如：

```text
http://192.168.100.2:8080
```

页面包含两个模块：

- 流量监控
- 防火墙配置

## 8. 流量监控演示

在 OpenWrt 控制台制造流量：

```sh
ping 223.5.5.5
opkg update
```

浏览器页面应显示：

- 接口名称
- IP 数量
- 总流量
- 当前速率
- 峰值速率
- 过去 40 秒折线图
- 每个 IP 的接收、发送、2s/10s/40s 平均速率

## 9. 防火墙演示

切换到“防火墙配置”。

添加 ICMP 阻断规则：

```text
协议：icmp
源地址：any
目的地址：any
端口：留空
动作：drop
```

点击新增规则后，页面会显示 nftables 输出。

在宿主机命令行验证：

```bat
ping OpenWrt_IP
```

此时 ping 应失败。

回到页面点击“清空实验规则”，再执行：

```bat
ping OpenWrt_IP
```

此时 ping 应恢复。

## 10. 录屏顺序

建议按以下顺序录制：

1. 展示项目目录和源码结构。
2. 展示 OpenWrt 虚拟机 IP 和联网状态。
3. 启动 `netpulse_server`。
4. 浏览器打开 NetPulse 页面。
5. 制造流量，展示图表和表格变化。
6. 添加防火墙规则，展示规则列表。
7. 用 ping 或浏览器验证规则生效。
8. 清空实验规则，展示网络恢复。
9. 展示报告草稿中的 AI 使用说明。

## 11. 常见问题

### 页面打不开

检查服务是否启动：

```sh
ps | grep netpulse
netstat -lntp | grep 8080
```

检查宿主机能否 ping 通 OpenWrt。

### 抓不到流量

检查接口名：

```sh
ip addr
```

重新指定接口启动：

```sh
./scripts/run_openwrt.sh eth0 8080
```

### 防火墙规则添加失败

检查 nftables 是否安装：

```sh
opkg install nftables
nft list ruleset
```

检查脚本权限：

```sh
chmod +x scripts/firewall.sh
```

### 添加规则后影响访问

执行清空：

```sh
/usr/local/netpulse/scripts/firewall.sh clear
```
