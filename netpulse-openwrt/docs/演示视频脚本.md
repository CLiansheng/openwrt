# 演示视频脚本

建议总时长控制在 4 到 5 分钟。

## 0:00-0:30 项目说明

展示项目目录，说明本实验实现了两个模块：

- Web 界面流量监控
- Web 界面防火墙规则配置

可以口述：

> 本项目基于 OpenWrt 实现网络应用程序开发，后端使用 C 语言和 libpcap 捕获流量，同时提供 HTTP 接口；前端通过浏览器展示实时流量数据，并支持防火墙规则配置。

## 0:30-1:10 OpenWrt 环境

展示 OpenWrt 虚拟机控制台：

```sh
ip addr
ping 223.5.5.5
opkg list-installed | grep libpcap
```

说明虚拟机网络正常，已安装运行依赖。

## 1:10-1:50 启动程序

执行：

```sh
cd /usr/local/netpulse
./scripts/run_openwrt.sh br-lan 8080
```

展示终端输出：

```text
NetPulse server listening on http://0.0.0.0:8080
Capture interface: br-lan
```

## 1:50-2:50 流量监控

打开浏览器：

```text
http://OpenWrt_IP:8080
```

展示：

- 接口名
- IP 数量
- 总流量
- 折线图
- 表格里的接收、发送、峰值、2s/10s/40s 平均速率

制造流量：

```sh
ping 223.5.5.5
opkg update
```

口述：

> 可以看到页面每秒请求 `/api/traffic`，后端返回 JSON 数据，前端实时刷新表格和折线图。

## 2:50-4:10 防火墙配置

切换到防火墙配置页面。

添加 ICMP 规则：

```text
协议：icmp
源地址：any
目的地址：any
端口：空
动作：drop
```

展示规则列表里出现 `netpulse:规则ID`。

宿主机执行：

```bat
ping OpenWrt_IP
```

展示 ping 失败。

回到页面点击清空实验规则，再执行：

```bat
ping OpenWrt_IP
```

展示 ping 恢复。

口述：

> 前端参数不会直接拼接成系统命令，后端会检查协议、地址、端口和动作，然后调用固定脚本完成 nftables 规则配置。

## 4:10-4:40 总结

展示 README 或源码关键位置：

- `src/netpulse_server.c`
- `scripts/firewall.sh`
- `web/app.js`

口述：

> 本实验完成了 OpenWrt 环境下的 C 语言流量监控、Web 可视化展示、防火墙规则配置与验证，满足实验任务要求。
