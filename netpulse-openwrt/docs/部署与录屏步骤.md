# 部署与录屏步骤

## 一、OpenWrt 虚拟机准备

1. 使用桌面上的 `openwrt-24.10.0-x86-64-generic-ext4-combined-efi.vmdk` 创建虚拟机。
2. 虚拟机网络建议选择 NAT。
3. 在 OpenWrt 控制台执行：

```sh
ip addr
vi /etc/config/network
/etc/init.d/network restart
ping 223.5.5.5
```

4. 记录 OpenWrt 的 IP 地址，后续浏览器访问使用。

## 二、安装运行依赖

```sh
opkg update
opkg install libpcap nftables
```

如果需要通过 Samba 传文件：

```sh
opkg install luci-app-samba4
```

也可以用 `scp`、WinSCP 或 VMware 共享目录传输。

## 三、上传项目

将项目目录中的这些内容上传到 OpenWrt：

```text
build/netpulse_server
web/
scripts/
```

建议放到：

```text
/usr/local/netpulse
```

最终目录：

```text
/usr/local/netpulse/netpulse_server
/usr/local/netpulse/web/index.html
/usr/local/netpulse/scripts/firewall.sh
/usr/local/netpulse/scripts/run_openwrt.sh
```

## 四、启动服务

```sh
cd /usr/local/netpulse
chmod +x netpulse_server scripts/*.sh
./scripts/run_openwrt.sh br-lan 8080
```

如果提示接口不存在，执行：

```sh
ip addr
```

把 `br-lan` 替换成实际接口，例如 `eth0`。

## 五、浏览器访问

在宿主机浏览器打开：

```text
http://OpenWrt_IP:8080
```

例如：

```text
http://192.168.100.2:8080
```

## 六、流量监控演示

在 OpenWrt 控制台制造流量：

```sh
ping 223.5.5.5
opkg update
```

或在宿主机访问 OpenWrt 页面：

```text
http://OpenWrt_IP
```

录屏时展示：

- Web 页面显示接口名
- 表格出现 IP 地址
- 接收/发送流量增加
- 折线图随请求变化
- 2s、10s、40s 平均速率和峰值速率变化

## 七、防火墙配置演示

在 Web 页面的防火墙配置中添加规则：

```text
协议：icmp
源地址：any
目的地址：any
端口：留空
动作：drop
```

然后在宿主机命令行执行：

```bat
ping OpenWrt_IP
```

应看到 ping 不通。再回到 Web 页面清空实验规则，重新 ping，应恢复正常。

也可以添加 TCP 端口规则：

```text
协议：tcp
源地址：any
目的地址：any
端口：80
动作：drop
```

然后验证 LuCI 或 HTTP 访问被拦截。

## 八、录屏收尾

录屏最后展示：

```sh
nft -a list table inet netpulse
```

然后在 Web 页面点击清空实验规则，避免影响后续网络环境。
