# OpenWrt SDK 交叉编译说明

本项目推荐使用 OpenWrt SDK 在 Linux 或 WSL 中交叉编译，避免在 OpenWrt 虚拟机中安装完整编译环境导致 overlay 空间不足。

## 一、准备 SDK

下载与系统版本和架构一致的 SDK。当前实验镜像为 x86-64 OpenWrt 24.10.0，可使用：

```text
openwrt-sdk-24.10.0-x86-64_gcc-*_musl.Linux-x86_64.tar.zst
```

解压：

```sh
tar -I zstd -xf openwrt-sdk-24.10.0-x86-64_*.tar.zst
cd openwrt-sdk-24.10.0-x86-64_*
```

本项目的 OpenWrt 版本采用运行时动态加载 `libpcap.so.1` 的方式，交叉编译阶段不需要在 SDK 内编译 libpcap 开发库。

## 二、编译 NetPulse

进入本项目目录：

```sh
cd /path/to/netpulse-openwrt
```

设置 SDK 路径。以下路径需要按实际 SDK 目录调整：

```sh
export SDK=/path/to/openwrt-sdk-24.10.0-x86-64
export STAGING_DIR=$SDK/staging_dir
export TARGET_DIR=$STAGING_DIR/target-x86_64_musl
export TOOLCHAIN_DIR=$(ls -d $STAGING_DIR/toolchain-x86_64_*_musl)
export PATH=$TOOLCHAIN_DIR/bin:$PATH
```

编译：

```sh
make clean
make openwrt-dynamic CC=x86_64-openwrt-linux-musl-gcc
```

生成文件：

```text
build/openwrt/netpulse_server
```

## 三、打包上传

```sh
make package-openwrt CC=x86_64-openwrt-linux-musl-gcc
```

生成：

```text
build/netpulse-openwrt-upload.tar.gz
```

上传到 OpenWrt 后解压：

```sh
mkdir -p /usr/local/netpulse
tar -xzf netpulse-openwrt-upload.tar.gz
cp -r netpulse-openwrt-upload/* /usr/local/netpulse/
cd /usr/local/netpulse
chmod +x netpulse_server scripts/*.sh
```

运行：

```sh
./scripts/run_openwrt.sh br-lan 8080
```

## 四、常见问题

### OpenWrt 运行时报找不到 libpcap.so.1

在 OpenWrt 中安装：

```sh
opkg update
opkg install libpcap
```

### 编译时报找不到 x86_64-openwrt-linux-musl-gcc

检查 SDK 工具链是否加入 `PATH`：

```sh
echo $PATH
ls $TOOLCHAIN_DIR/bin/x86_64-openwrt-linux-musl-gcc
```
